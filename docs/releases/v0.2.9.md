# Grok plugin v0.2.9 — release notes

**Plugin version:** `0.2.9`  
**Previous release:** `v0.2.8`  
**Severity:** Security + correctness. Billing strip, `--always-approve`, and no-auto-commit are unchanged.

---

## Summary

A SonarCloud "Overall Code" style audit of `mcp-server/src`, cross-verified with Grok Build,
turned up six defects with real behavioural or security consequence. Every one was reproduced
before it was fixed, and every fix landed test-first.

The two that matter most: the v0.2.8 history redaction only matched **bare** `KEY=value`, so a
key pasted in JSON/`.mcp.json` shape was written to `~/.grok-build/history.jsonl` in the clear;
and `worktree apply` derived `filesChanged` by scraping `+++ b/` lines out of the patch, which
silently dropped every deletion, every pure rename and every non-ASCII path from the list a
human reviews before committing.

---

## What changed

- **History redaction (`history.ts`).** The key-assignment pattern now accepts quoted keys, so
  JSON (`{"XAI_API_KEY": "…"}`), quoted `.env` and YAML shapes are masked — previously only
  `KEY=value` was. A second pattern redacts a bare `xai-…` token pasted with no variable name.
  Measured: 5 of 8 realistic paste shapes leaked before; 0 of 8 now. Prose such as `xai-cli` is
  deliberately left alone.
- **`worktree apply` change list (`worktree.ts`).** `filesChanged` now comes from
  `git diff --cached --name-only -z` (with `core.quotepath=false`) instead of parsing the patch
  body. Fixes four defects at once: deletions and 100% renames were missing entirely, non-ASCII
  paths were C-quoted and dropped, names containing spaces kept a trailing TAB, and a line of
  file **content** beginning with `++ b/` was reported as a changed file that never existed.
  The patch capture now passes `core.quotepath=false` too, matching `worktree diff`.
- **Patch temp file (`worktree.ts`).** The patch is written into a `mkdtempSync` directory
  (unpredictable, `0700`, atomic) with mode `0600`, and the whole directory is removed
  afterwards. It was a clock-derived, fully predictable name written directly into the shared
  temp dir with the default `w` flag — on a shared POSIX host that is a world-readable copy of
  the source diff plus a symlink-pre-creation write primitive. Sonar `S5443`/`S2612`.
- **PATH key casing (`env.ts`).** `prependGrokBin` locates the PATH key case-insensitively.
  Windows spells it `Path`; writing a fresh uppercase `PATH` beside it left two keys differing
  only in case, and the child process keeps just one — so grok could inherit its own bin dir as
  the entire PATH. This mirrors the case-insensitive key handling `buildGrokEnv` already used.
- **`--model` passthrough (`delegate.ts`).** The retired-alias check uses `Object.hasOwn`
  instead of `in`, which walked the prototype chain: a model named `toString`, `constructor`,
  `valueOf`, `hasOwnProperty` or `isPrototypeOf` was treated as retired and `--model` was
  silently omitted. `grok-build` is still omitted, as intended.
- **`grok_cli` cwd (`grok-cli.ts`).** A relative `cwd` is now rejected before spawning, the same
  guard `runDelegate` already applied. It previously resolved against the MCP server's own
  directory and surfaced as a misleading "grok 실행에 실패했습니다 (설치/PATH 확인)".

A second-opinion pass by Grok Build (isolated worktree, real reproductions) confirmed all six
and drove two further hardenings: `prependGrokBin` prefers an exact uppercase `PATH` when a
hand-built env carries both spellings (measured: the child keeps the uppercase slot), and the
patch write moved inside the try so a throwing write cannot leak the 0700 directory.

Auth handling, the subscription env strip, `--always-approve`, and no auto-commit are unchanged.
The MCP surface is still the same 9 tools.

## Tests

The suite grew by twelve cases (`npm test` is the SSOT for the count — a hardcoded endpoint
drifts). New coverage includes a real-git integration test that creates a worktree containing a
deletion, a rename, a non-ASCII filename, a name with spaces and a content-forged `++ b/` line,
and asserts the exact `filesChanged` list.

---

## How to update

Marketplace update/reinstall → `/reload-plugins` → `claude plugin list` enabled →
`/grok:status` `serverVersion` **0.2.9**. Cache is version-keyed; do not reuse 0.2.8.
