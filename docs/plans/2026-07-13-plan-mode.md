**Goal:** Add a read-only `grok_build_plan` MCP tool that returns grok's plan for a task without editing files.

**Architecture:** A new tool reuses `runDelegate` via `input.plan`; plan mode uses `--permission-mode plan` (not `--always-approve`), treats a parsed-with-text result as success (grok ends `Cancelled`), and skips `git status` (`filesChanged: []`).

**Tech Stack:** TypeScript (ESM, NodeNext), `@modelcontextprotocol/sdk` ^1.29.0, zod ^3.25.0, vitest, esbuild.

## Global Constraints

- Plan mode makes NO edits: use `--permission-mode plan`, never `--always-approve`; `filesChanged` is always `[]` (skip `git status`).
- Success in plan mode = parsed result WITH non-empty text (stopReason `Cancelled` or `EndTurn`); empty text ⇒ `grok_error`.
- Non-plan delegate behavior must be unchanged (existing tests green).
- Auth/billing/history path is shared with `grok_build_delegate`.
- `dist/index.js` is a committed esbuild bundle — `npm run build` before committing after `src/` changes. TDD; run from `mcp-server/`.

- [ ] **Step 1: Register the tool** — in `index.ts`, after the `grok_build_delegate` `registerTool(...)` call, add:

```typescript
  server.registerTool(
    'grok_build_plan',
    {
      description: 'Ask Grok Build for a plan/approach for a task WITHOUT editing any files (read-only preview). Use before grok_build_delegate to preview grok\'s approach; returns a plan summary.',
      inputSchema: z.object({
        prompt: z.string().describe('Task instruction for grok (English recommended).'),
        cwd: z.string().describe('Absolute path of the working directory.'),
        timeout_ms: z.number().int().positive().optional().describe('Default 180000 (3 min).'),
      }),
    },
    async ({ prompt, cwd, timeout_ms }) => {
      const pre = checkAuth(mode, defaultAuthDeps());
      if (!pre.ok) {
        return { content: [{ type: 'text', text: pre.message }], isError: true };
      }
      const input = { prompt, cwd, timeoutMs: timeout_ms, plan: true };
      const t0 = Date.now();
      const result = await runDelegate(mode, input);
      recordDelegation(input, result, { ts: new Date().toISOString(), durationMs: Date.now() - t0 });
      return {
        content: [{ type: 'text', text: JSON.stringify(result, null, 2) }],
        isError: result.status !== 'completed',
      };
    },
  );
```
