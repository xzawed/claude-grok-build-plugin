# v0.2.15 — 취약점 6건, 그중 4건은 실제로 배포되고 있었다

2026-09-03. Dependabot이 올린 경보 6건을 처리했다. 코드 변경은 없고 lockfile과 번들만 바뀐다.

## 무엇이 사용자에게 도달했는가

CLAUDE.md의 규칙대로 **패키지마다 번들 도달 여부를 실측**했다 — 이름만 보고 판단하지 않는다.

```
grep -c "node_modules/fast-uri/" dist/index.js   →  6   ← 인라인됨, 사용자에게 도달
grep -c "node_modules/qs/"       dist/index.js   →  0   ← 번들 밖
grep -c "node_modules/express/"  dist/index.js   →  0   ← 번들 밖
```

| 패키지 | 경보 | 심각도 | 설치본 → 패치 | 번들 도달 |
|---|---|---|---|---|
| `fast-uri` | 4건 (host confusion ×2, SSRF ×2) | **high** | 3.1.5 → **3.1.7** | **예** |
| `qs` | 2건 (array-limit bypass, DoS) | medium | 6.15.3 → **6.16.0** | 아니오 |

`fast-uri`는 `ajv`를 거쳐 MCP SDK에서 들어오고, esbuild가 런타임 의존성을 번들에 인라인하므로
**설치한 사용자가 실행하는 코드에 취약한 버전이 들어 있었다.** high 4건이 이론이 아니었다는
뜻이다. `qs`·`express`는 SDK의 HTTP 전송 계층에 속하고 이 stdio 서버는 그 경로를 로드하지
않는다 — PR #48(`ip-address`)과 같은 케이스라 번들에는 영향이 없지만, 경보를 남겨둘 이유도
없어 lockfile에서 함께 올렸다.

## 어떻게 고쳤는가

`npm audit fix` — 의존성 변경은 **lockfile에만** 있다(8 insertions / 8 deletions).
`package.json`의 의존성 범위는 그대로이고, 이 커밋이 거기서 함께 건드리는 것은 버전 필드뿐이다.
새 override도, SDK 버전 변경도 없다. 확인:

```
@modelcontextprotocol/sdk   installed 1.29.0 | lock 1.29.0    ← 드리프트 없음
fast-uri                    installed 3.1.7  | lock 3.1.7
qs                          installed 6.16.0 | lock 6.16.0
npm audit                   → 0 vulnerabilities
```

SDK 버전을 대조한 이유는 `CLAUDE.md`의 실측 사례 때문이다 — 2026-08-23에 `npm i --no-save`가
런타임 의존성을 조용히 올려 소스와 어긋난 번들을 커밋할 뻔했다. 그래서 의존성이 바뀌면
**반드시 `npm ci` 후에 빌드**하고, 설치본과 lockfile을 대조한다.

## 번들 변경이 벤더 영역에 한정되는지 확인했다

재빌드 후 `dist/index.js`가 409행 추가 / 126행 삭제로 바뀌었다. 변경 hunk는 **54개**이고 그중
**53개가 `fast-uri` 영역**(`index.js` 28 · `lib/utils.js` 21 · `lib/schemes.js` 4), 나머지 1개는
버전 문자열(`0.2.14` → `0.2.15`)이다 — 플러그인 로직은 한 줄도 바뀌지 않았다.
`dist/hook.js`도 그 버전 문자열만 바뀐다(이 번들은 fast-uri를 포함하지 않는다).

**패치본이 실제로 들어갔는지도 lockfile 말만 믿지 않고 확인했다.** 3.1.7에만 있는 문자열
`URI host is malformed.`(`node_modules/fast-uri/index.js:499`)이 새 번들 `dist/index.js:4128`에
있고 **이전 번들에는 없다**. `hasBracket`·`isIPLiteral`도 같은 결과다. 즉 lockfile이 아니라
**배포되는 산출물** 기준으로 패치를 증명했다.

## 버전

`v0.2.14`는 태그와 릴리스가 이미 나갔고 이번에 **번들이 바뀌므로** 0.2.15로 범프했다.
캐시는 버전 키다 — 같은 번호로 다른 번들을 내보내지 않는다.

- `npm audit` **0 vulnerabilities**, Dependabot 경보 6건 해소
