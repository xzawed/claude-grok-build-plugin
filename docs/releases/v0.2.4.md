# Grok plugin v0.2.4 — release notes

**Plugin version:** `0.2.4`  
**Previous release:** `v0.2.3`  
**Severity:** **Critical fix** — plugin failed to load in current Claude Code

---

## Summary

Fixes a **plugin load failure** that hid **all** `/grok:*` slash commands after install or upgrade, even though files were present on disk.

---

## What went wrong (v0.2.3)

Claude Code reported:

```text
grok@grok-marketplace
Status: failed to load
Error: Hook load failed: expected record at path ["hooks"], received undefined
```

`hooks/hooks.json` used a bare event map (`{ "PreToolUse": [...] }`).  
Current Claude Code expects the **wrapped** plugin shape (`{ "hooks": { "PreToolUse": [...] } }`), matching official plugins.

---

## Install / update

```
/plugin marketplace add xzawed/claude-grok-build-plugin
/plugin install grok@grok-marketplace
/reload-plugins
```

Then verify:

1. In a terminal: `claude plugin list` → `grok@…` **Status: enabled**
2. In Claude Code: `/grok:status` → `serverVersion` **0.2.4**

If you still see the old set of commands, **fully quit Claude Code** and reopen (stale sessions may keep a failed load).

---

## What else is in 0.2.x

Same product surface as [v0.2.3](./v0.2.3.md): subscription-safe billing, status dashboard, route/`nextAction`, review/resume, worktree, first-mile tour — plus this load fix and a regression test so the hooks schema cannot silently break again.
