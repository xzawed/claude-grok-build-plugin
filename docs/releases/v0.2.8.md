# Grok plugin v0.2.8 — release notes

**Plugin version:** `0.2.8`  
**Previous release:** `v0.2.7`  
**Severity:** Reliability + security hygiene. Billing strip and no-auto-commit are unchanged.

---

## Summary

v0.2.7 matched Grok CLI 1.0.3 flags, but a successful (or plan) JSON whose **text mentioned
`grok login`** was reclassified as `auth_error`. Parse-fail auth errors also dropped
`filesChanged`. This release fixes the classifier, redacts API-key assignments in history
previews, and strips billing keys case-insensitively.

---

## What changed

- Success/`plan` assistant text is **not** scanned for `AUTH_ERROR_SIGNALS`. The measured
  unauth path remains `type: "error"` + “Not signed in”.
- Parse-fail `auth_error` still returns the git `filesChanged` delta.
- History `promptPreview`/`summaryPreview` replace `XAI_API_KEY=` / `GROK_CODE_XAI_API_KEY=`
  values with `<redacted>`.
- `buildGrokEnv(subscription)` deletes those key names **case-insensitively** (Windows env).
- Living-doc SSOT: `docs/03` version/command list, `docs/06` verify/`best_of_n`,
  `grok-cli-contract` §3–§4, CLAUDE Windows hook line.

Auth, `--always-approve`, and no auto-commit are unchanged.

---

## How to update

Marketplace update/reinstall → `/reload-plugins` → `claude plugin list` enabled →
`/grok:status` `serverVersion` **0.2.8**. Cache is version-keyed; do not reuse 0.2.7.
