# Grok plugin v0.2.7 — release notes

**Plugin version:** `0.2.7`  
**Previous release:** `v0.2.6`  
**Severity:** Compatibility — Grok Build CLI 1.0.3 / default model Grok 4.6 broke the
headless contract this plugin was measured against (0.2.93).

---

## Summary

Installed grok **1.0.3** emits `"stopReason": "end_turn"` and removed `--check` and
`--best-of-n`. v0.2.6 classified every successful delegation as `grok_error` and
`/grok:verify` died before the model ran. This release matches the 1.0.3 contract.

Auth, billing stripping, worktree isolation, and no-auto-commit are unchanged.

---

## What changed

- Success = `end_turn` **or** legacy `EndTurn` (`isSuccessfulStopReason`).
- `grok_build_verify` appends a verification prompt; it no longer passes `--check`.
- `best_of_n` is rejected without spawn (flag gone).
- Model id `grok-build` omits `--model` (CLI default is `grok-4.6`).
- `grok import` is blocked (not a subcommand; would start the TUI).
- `buildGrokEnv` sets `HOME` when neither `HOME` nor `GROK_HOME` is set (Windows `grok du`).

Contract: `docs/specs/grok-cli-contract.md`. Design: `docs/specs/2026-08-14-grok-1.0-compat-design.md`.

## How to update

Marketplace update/reinstall → `/reload-plugins` → `claude plugin list` enabled →
`/grok:status` `serverVersion` **0.2.7**. Cache is version-keyed; do not reuse 0.2.6.
