## F5 — 컨테인먼트 가드가 심볼릭 링크 조상을 놓칠 수 있었다 (`src/worktree.ts`)

`isPathInsideBase`는 `git worktree remove --force`가 **baseDir 아래만** 지우도록 막는 가드다.
그 본문이 `realpathSync` **두 개를 하나의 try/catch로** 감쌌다:

```ts
try { cand = realpathSync(...); base = realpathSync(...); }
catch { cand = resolve(candidate); base = resolve(baseDir); }   // ← 둘 다 강등
```

`realpathSync`는 **마지막 구성요소가 없으면 throw** 한다 — 제거하려고 넘기는 경로의 정상적인
모습이다. 그 순간 후보의 **조상에 걸린 심볼릭 링크도 함께 해석되지 않았고**, 가드는 문자열
비교로 떨어졌다. `<base>/out`이 바깥을 가리키는 junction이면 `<base>/out/missing`이
"안쪽"으로 통과한다.

**적대적 리뷰(Grok)가 정적분석으로 찾았다** — `GUARD_HAS_A_HOLE`. 같은 리뷰가 win32에서
`startsWith`가 대소문자를 구분해 **정당한 제거를 거부**하는 오거부도 짚었다.

**수정:** 두 경로를 **독립적으로** 해석하고, 후보는 `realpathDeepest`로 **존재하는 가장 깊은
조상까지 realpath한 뒤 나머지를 다시 붙인다**. win32에서는 비교를 소문자로 정규화한다.

⚠️ **과장하지 않는다.** 제품 도달성은 함수 단독보다 좁다 — `git worktree remove`는 **git이
등록한 worktree**에만 작동하므로 2차 방벽이 있고, 이 구멍만으로 임의 디렉터리가 지워지지는
않는다. 실제로 열려 있던 것은 **방어심도의 구멍과 테스트 부재**다(기존 테스트는 4개 케이스만
고정했고 realpath 실패 경로가 없었다). 회귀 테스트 3개를 추가했다 — 심볼릭 링크 조상, 없는 leaf가
있어도 정상 자식은 통과, win32 대소문자.

## F4 — 감사 하네스가 호출자의 `timeout_ms`를 무시하고 240초에 끊었다 (`.claude/tools/`)

`docs/10`이 재현의 표준 도구로 지정한 `mcpcall.mjs`가 RPC 타임아웃을 **240초로 하드코딩**하고
tool 인자의 `timeout_ms`를 **읽지 않았다.**

**실측:** `timeout_ms: 900000`을 실은 위임이 **정확히 240초**에 끊기고
`TRANSPORT FAILURE: timeout on tools/call`만 남았다 — 서버 행·느린 모델과 **구분 불가**.
상수를 1ms로 바꾸자 밀리초 만에 끝나는 호출의 `initialize`가 실패해, 지배하는 것이 하네스임이
확정됐다.

A26이 고친 것과 같은 계열이다 — 그때는 "죽은 자식을 못 본다"였고, 이번엔 "정당하게 긴 호출을
표현하지 못한다"다. **규정된 절차를 믿는 사람에게 조용히 증거를 위조한다**는 점이 같다.

**수정:** 규칙을 `.claude/tools/rpc-timeout.mjs`로 분리해
`max(기본 240초, timeout_ms + 30초 여유)`로 만들고, 캡에 걸리면 **"harness cap, not the server"**
라고 말하게 했다. 여유를 두는 이유는 **서버가 자기 캡을 구조화된 `status: "timeout"`으로**
돌려주는 편이 훨씬 유용하므로, 하네스가 그 경주에서 일부러 져야 하기 때문이다.
`mcp-server/test/mcpcall-timeout.test.ts`가 규칙을 고정한다 — 240초 리터럴 복귀도 막는다.

## F3 — `.claude/`가 "배포 안 됨"이라고 적혀 있었다 (`CLAUDE.md`)

**실측:** 설치 캐시 안에 `.claude/`가 그대로 있고, `accept-release.mjs`·`mcpcall.mjs`가 레포
파일과 **바이트 동일**하다. 마켓플레이스 소스가 `./`라 레포 전체가 버전 키 캐시로 복사된다.

사실인 것은 **로드·실행되지 않는다**이고, "배포 안 됨"은 틀렸다. 적대적 리뷰가 피해를 정확히
짚었다 — 그 문장을 믿고 **비밀값이나 위험한 스크립트를 거기 두면 모든 사용자 디스크로 내려간다.**
